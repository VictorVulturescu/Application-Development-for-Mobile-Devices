# ADMD

Shared Flutter application for the Application Development for Mobile Devices labs.
The lab 2 users, accounts, and library exercises are retained.

## Run

```sh
cd admd
flutter pub get
flutter run
```

## Check

```sh
flutter analyze
flutter test
```

The Dart package and project directory are named `admd`; the displayed app name is
`ADMD`. Platform application IDs are retained to preserve the existing app identity.
